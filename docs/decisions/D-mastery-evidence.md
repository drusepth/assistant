**D-mastery-evidence. Mastery is a per-topic state machine advanced only by evidence — and honest enough to go backwards.**
Each topic carries `unseen → learning → practicing → mastered`, plus **`rusty`** — the demotion FSRS predicts when a mastered topic's reviews lapse past the retention target. Forward transitions happen on evidence only: a passed retrieval check (`quiz_me`), a tutor checkpoint verdict from a session that actually probed, a teach-back, or the learner's own say-so (allowed — their school, their record — but recorded *as* self-marked). Never on time elapsed, lessons "viewed", or tasks checked off: school holds time fixed and lets mastery vary, and this hub inverts that — mastery fixed, time variable — which is the whole Bloom two-sigma play and the reason there are **no letter grades anywhere**: a topic is mastered, or not yet. Progress in the UI is always the state mix over topics; pace is measured only against the learner's own optional target date, never an age-grade norm. `rusty` is the state most products refuse to draw and the honest one: memory decays, and a hub showing fractions forever-green while the kid can no longer do them is lying exactly where it matters most — mastered means *maintained*, re-earned through the same evidence, usually in minutes. Full design in `EDUCATION_PLAN.md`. — *Built (W2): quiz_me is the retrieval gate, placement stamps starting states, the tutor proposes checkpoints only when the session probed; W3 added the rusty demotion and its shore-up.*
