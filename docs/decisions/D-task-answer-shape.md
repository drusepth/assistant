**D-task-answer-shape. A task page leads with the answer card and the conversation only for thinking work**

Amends D30. Every task page used to open with an empty "Your answer" card and a full chat panel, which reads as nonsense on "Scoop litter" or "Buy batteries". The model already decides which kind of task it is at capture: `Tasks::Categorize` and `Goals::BreakDown` write `guiding_questions` only for mental work and leave them empty for errands. So `Task#mental_work?` is just "has stored questions", and the page leads with the answer card and the chat panel only when that is true, when an answer is already saved, or when a conversation is under way. Otherwise the answer card folds to an "Add an answer" line, and the chat becomes the one-line "Talk it through" door at every width. No new column and no extra model call. Empty questions also mean "never classified" (made by hand, imported, pre-D30, no model configured). That ambiguity is harmless here because both cases get the same folded treatment, and the fold is its own override: one click opens it. The one thing this adds to D30: **opening questions are now also the page-shape signal**, so never backfill them with stock text to make every conversation open with something — the fallback opener belongs in `conversation_openers`, not in the column. If "errand vs thinking work" ever needs to mean something beyond this page, give it its own column then.
