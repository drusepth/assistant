**D-allergy-notes. An allergy is a Note with a kind, plus one structured severity field.**
D36's shape one rung further: the Allergies card files a Note (`notes.kind = "allergy"`, allergen as title, reaction as body) under Health, so it exports, shares, and reaches the tools unpaid. What it adds is `notes.severity` (severe / moderate / mild, nullable) — a narrow primitive-level column like `events.care_kind`, earned because severity is the only fact about an allergy that changes what anyone does about it. Optional on purpose: the form defaults to "Not sure" and unrated allergies sort *last*, not as mild — an unrated allergy is an unanswered question, not a small one. Doctor-visit prep reads them as their own worst-first block, ignoring section tags (an allergy is one whether or not the note got filed under Health) and told to repeat the list verbatim — this is the D36 note's "call the list out explicitly instead of diluting it in generic notes context", taken where dilution costs the most. Deliberately not built: cross-reactivity warnings or interaction checks against the med list — that is diagnosis wearing a helpful hat, and the Health scoping line forbids it. — *Built.*
