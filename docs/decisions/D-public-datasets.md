**D-public-datasets. Public data ships as local datasets: seeds + refresh + import, staleness always visible.**
Between owned data and the live web sits published public data, and it is served **locally**: a two-layer lookup (`storage/datasets/` — written by `RefreshDatasetsJob` or an admin file import — wins over `db/datasets/` seeds), with every consumer displaying the data's vintage. The repo seeds only what is small and stable (the CPI-U annual-average series); the OES/OEWS national wage table ships **without** a seed and arrives via the refresh job (BLS API for CPI, the published national zip parsed by a minimal streaming xlsx reader for wages) or via `/admin`'s file import for air-gapped installs — we never bundle numbers we can't verify at build time. Consumers degrade to absence, not to guesses: no dataset → the placeholder behavior the tools already had. First consumers: the real-terms-drift watcher (CPI × the D-career-signal comp timeline, pure arithmetic at nudge time) and the raise case's buying-power and closest-median lines. Non-US datasets are additions to the same layer, not a redesign. — *Built.*
