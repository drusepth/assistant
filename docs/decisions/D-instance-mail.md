**D-instance-mail. Instance mail is optional and never load-bearing.**
The instance's own outgoing mail is an operator convenience configured from `SMTP_*` ENV, any provider, and nothing in the app depends on it. D15 already kept invitations off email; this closes the one path that still did. **Password reset** works by a handed-over link: a household admin makes one for another member from the Household page, and the operator can always make one from the shell (`bin/rails password:reset_link EMAIL=…`), which is the way back in for a solo household whose only admin forgot the password. The handed link is its own token purpose, lives 24 hours rather than Rails' 15 minutes because it travels by text or in person, and dies when the password changes, like the emailed kind. The email form is only offered when instance mail is configured *and* `APP_HOST` is set; the reset link is never built from a request's Host header, which is the reset-poisoning hole. **Email notifications** send through the user's own linked mailbox when they pick one (from them, to them, over their SMTP, which no spam filter doubts), or through instance SMTP when it exists; with neither, Settings says what would make email work instead of taking an address it cannot send to, and a channel that loses its sender later stays listed with the reason and is skipped at send time. **Rejected: sending without a relay.** Direct-to-MX from a home server does not land in spam, it does not arrive: residential ISPs block port 25, residential addresses are on the blocklists the large providers consult, and Gmail and Yahoo refuse mail without SPF, DKIM, and matching reverse DNS. **Accepted trade-off:** an admin's reset link lets the admin into that member's account. The password vault and diary stay sealed without the member's recovery code (D-vault-crypto), the member is signed out everywhere and finds their old password dead, and the issue is logged; the rest of the account was already within reach of an admin who can delete it outright. Operator setup in `docs/MAIL.md`. — *Built.*
