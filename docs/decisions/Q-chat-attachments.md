**Q-chat-attachments. Sending a photo or a document into a conversation.**
"Here's a photo of the problem" is the first thing a phone user will try in the tutor, and "here's the letter" in `what_do_i_say`. The primitives (Photo, Document) and the storage seam already exist, but it needs a vision-capable endpoint — which most self-hosted ones are not — so it waits on Q9's capability question, and whatever ships must degrade honestly rather than silently dropping the image. — *Not started.*
