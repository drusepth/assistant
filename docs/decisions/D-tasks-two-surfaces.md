**D-tasks-two-surfaces. The Tasks section is one section with two surfaces: the board (default) for daily doing, a Goals tab for occasional planning.**
Interaction frequency decides screen real estate. Tasks change state daily; goals change a dozen times a year — yet the page led with a full grid of tall goal cards that pushed the Today column several phone-screens down. This does not un-merge D17 (one section, one capture box, one data model stand); it splits the *rendering* by cadence. The board surface keeps the capture box and compresses active goals into the **strip D17 already called for**: one horizontally-scrollable row of compact chips — title, progress or momentum (D-goal-shape), and a flag when something needs the user (stale per D-goal-pause, or no next step). The strip is ordered by **needs-attention, deterministically, in Ruby** (a task in Today first, then goals adrift with no dated next step, then by recency of progress) — never `created_at`, which carries no information, and never a model call. The **Goals tab** (`tasks?tab=goals`, same controller action) is the planning destination: the big gradient cards, paused goals, and the achieved archive — kept because history is an asset ("look what you finished"), not clutter. A mode *toggle* between peers was explicitly rejected: hierarchy beats modes — one default surface for doing, one destination for reflecting, which is also where the industry converged (Things' Today-first, Asana's Goals tab, OKR tooling's review cadence). Submitting the capture box lands you **on the goal's own page** while the breakdown streams in — the goal page is the bridge between modes: you watch the plan form, edit it, pull a task into Today, and by tomorrow the goal has receded to a chip while its scheduled steps surface themselves on the board. On phones the three board columns become **swipeable snap panes with a Later | Today | Done tab bar, opening on Today**, so present state is the first thing visible; desktop keeps the three-column grid. — *See `docs/TASKS_PAGE_PLAN.md`.*
