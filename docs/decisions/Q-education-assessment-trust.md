**Q-education-assessment-trust. When the record matters externally, does mastery need anchors the model didn't grade?**
Self-graded and model-graded mastery is right for learning (low stakes, fast feedback) — but a transcript a third party reads may want calibration from outside the loop. Likely shape: import scored standardized practice tests as Documents linked to subjects — external anchors, owned like everything else, never a gate on learning itself. Decide after real use.
