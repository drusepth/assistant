**Calendar shows tasks and reminders, with layer toggles**: the month showed only Events (and the travel band), so a task with a due date and every reminder were invisible on the one view meant to be holistic. Tasks now sit on their due date (visible-to scoped like events, section-colored chip led by a check mark, done ones struck through), and reminders on each moment they'll fire — the viewer's own only, since a reminder is delivery rather than shareable content; a standing reminder expands its rule forward from the occurrence it has armed (past fires aren't stored, so a past month shows only one-shots). A row of Events / Tasks / Reminders toggles above the grid picks what shows: each toggle is a `?layers=` link and the choice is remembered in a cookie, so the month reopens the way you left it. On phones the dots tell kinds apart by shape — events round, tasks square, reminders rings. The cell rendering split into `calendar/_event`, `_task`, `_reminder` and `_dot` partials; a `bell` icon joined `ICON_PATHS`.
