**Pet lenses no longer offered as People groups**: every pet owns a custom child section of People (D-pet-primitive), so "about Rex" works as a tag. The People-page circle cards already left those lenses out, but the person page's "Add to group" picker, the Address Book's group chips and the membership endpoint read People's raw children. That is how a vet made from the pet form got offered "Add to group → Dimitri". `Section.people_groups` is now the one definition (People's children minus every `LENS_OWNERS` lens, done as subqueries so the chip query count stays flat), and all four surfaces read it.
