**The document intake plan (`docs/INTAKE_PLAN.md`; D-landing-registry, D-document-intake, Q-intake-stated-due, Q-intake-edit-in-review)**: the design conversation for what happens after a document is uploaded — occasioned by a photo of a vet's discharge sheet that uploads, files to Rex in one click, and then sits there, because `Documents::Analyze` reads PDFs and text only and even for a PDF produces a summary and nothing the visit implies. The plan refuses the obvious fix (a `VET_VISIT_FIELDS` beside `PAY_STUB_FIELDS`) on the grounds that the app already has three independent "model proposed a row, code writes it" paths — `ToolRun#land_one`, `Suggestion#materialize`, `extracted_facts` — none sharing a definition, and intake would be the fourth. Instead: **one landing registry** (`app/landings/`, on the `Tool::SLUGS` pattern) where each kind's class declares its fields once and the prompt paragraph, the validation into the closed set, the write, and the review-page preview are all derived from that declaration — so the model is told exactly what the code can write, and nothing else. The drift guard is a test: every `Users::Export::MODELS` key is produced by a kind or excused on `Landing::NOT_INTAKE` with a reason. The document is the run: analysis (text, PDF, or images and scans through the vision rung photos already use) writes validated landings onto `documents.landings`, `/documents/:id/review` is a checklist under the prepared-work copy that nothing exists yet, Save lands the checked ones in one transaction with provenance in `document_items`, skipped ones are remembered, and the file is always kept. Five waves: W1 reads images (independent, general value), W2 the registry + review page + event/task/note/person with `ToolRun#land_one` moved onto it, W3 the health and pet kinds (medication, allergy, `pet_facts` amendments, `pet_food`, `care_kind`) — the wave that lands the vet report — W4 spending and the `health_plan` pin that retires the `Health::Coverage` keyword match, W5 the presence/detail split for small models. Not started.
