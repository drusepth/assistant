**The cloud is a checkbox you can uncheck**: `model_profiles.allow_cloud_models` (boolean, default **true**) plus the UI that argues against leaving it on. Unticking it takes every `cloud: true` preset out of the picker, a model validation refuses to save the pair, and `#client` raises rather than call a provider the household has said no to — belt for the app path, braces for a hand-edited row. The picker is now two `optgroup`s with "Runs where you put it" **first** and "Cloud providers" second, and the callout above them makes the case the mission has always implied but the settings page never said out loud: your data stays yours, nobody logs your prompts or changes their mind later about what they keep, an assistant you rent can be repriced or switched off and one you run cannot, and no per-token bill means thinking harder about your own life never gets more expensive (D-local-first-models). Three deliberate limits. It is **not a firewall** — the self-hosted preset is free text, so you can uncheck the box and type OpenAI's URL, and the copy says so rather than implying a guarantee the app can't make. It is **not the default** — cloud-off with no one-click local setup yet would hand a new household an assistant that does nothing, and D9 says the user makes this choice visibly, not that we make it for them. And it is **not vapour**: local models already work through the self-hosted endpoint, so that group is honest today; what's missing is the setup flow, which is what the copy promises. Driving the real form in a browser caught the two bugs that mattered, both invisible from tests: switching to the local option pre-filled the base URL with `https://api.openai.com/v1` (the column's default, one Save from being true), so the field now renders only a URL the household actually chose and leans on a `localhost:11434` placeholder; and the model box went blank with no guidance, so it gained a hint naming `llama3.2`/`qwen3` and `ollama list`, alongside a key hint saying most local servers don't want one. The gate reads the preset key, not a hardcoded list, so a first-class `ollama` preset lands later by simply omitting `cloud:`. New `.callout` atom (+ `-warn`, `-title`) for a tinted aside that belongs to a form rather than to the request.
