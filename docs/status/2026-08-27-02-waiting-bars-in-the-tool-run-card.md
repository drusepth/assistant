**Waiting bars in the tool-run card**: a queued or running tool run showed one grey sentence and nothing else, which on a phone reads the same as a page that has quietly given up. It now leads with `.working-bars` — a row of rounded columns spanning the card wall to wall, standing on one baseline and riding one wave, added as an atom in `app/assets/tailwind/application.css` beside the chat and celebration motion. The loop is one 1.4s `scaleY` keyframe shared by every bar, each offset by a fourteenth of the period, so a crest walks across the row and wraps into itself: nothing restarts, so there's no seam for the eye to catch on the fifth minute of watching it. Only `transform` animates — this can sit on screen for as long as a model takes, and a keyframe that touched height would relayout the card on every frame. Four details that aren't obvious from the rules: **full width lives in the flex box, not in the bar count**, so one markup fits a phone and a `max-w-3xl` card both — each bar is `flex-1` off a zero basis but capped at 10px, and `justify-between` spends the slack a wide card leaves on the gaps, which keeps bars bar-shaped on a laptop instead of fattening them into slabs; **the phase repeats every 14 bars** (`nth-child(14n + …)`) rather than one rule per column, so a caller picks whatever count suits and the wave keeps its shape — the card renders 28, two full wavelengths, so the pattern meets both edges at the same point; the bars carry a **resting** `scaleY` sampled off the keyframe at their phase rather than defaulting to full height, because the app-wide reduced-motion floor at the foot of the file collapses the animation to a single 0.01ms pass and what it falls back to should still be a wave frozen mid-travel rather than a row of identical sticks (this atom *wants* that floor — a decoration saying "still working" adds nothing the sentence under it doesn't, so unlike `.celebrate-banner` it doesn't opt out); and the whole group is `aria-hidden`, leaving the sentence as the only thing a screen reader meets.
