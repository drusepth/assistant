**The active-agent plan (`docs/AGENT_PLAN.md`; D-agent-prepared-work, D-suggestion-lifecycle, D-decision-links, D-agent-earned-dials)**: the design conversation for what the Agent mode becomes beyond M3/M4's suggest-only build — the next rung of the D6 trust ladder, defined by what it refuses to change: D20 keeps its click, Q19 stays parked, and "Active" stops meaning merely *daily and louder* and starts meaning *the agent arrives with the work already done*. Four gaps drive five waves. A1 (model-free, first on purpose) gives suggestions a lifecycle: a `resolved` status for nudges the world already handled, an inverse `resolved?` hook on `Watcher::Base`, and an `expires_on` payload key so nothing outlives its moment — the D-reminders trust rule restated for the agent. A2 is the flagship: a watcher's `tool` action payload is already a tool invocation nobody clicked yet, so the scan pre-runs it — Active-dial sections only, behind a `prepare_work` toggle and a hard per-scan budget, since this is the first agent feature spending model tokens unbidden — with the `Tool::Base` landing helpers writing intents into `output["landings"]` instead of rows; accept opens a finished draft and the Save click is the D20 accept, materially identical to having run the tool yourself. A3 resolves Q-sms-replies toward the signed link, simplified from single-use to expiring because the session authorizes and decisions are idempotent — one URL in every channel payload, so the notice-review-save loop closes on the phone that received the text, NAT and modem included. A4 makes the dials earned rather than configured: a sectionless `dial_tuner` watcher offers Active once-ever to a section whose suggestions get accepted, and offers to pipe down in one that gets dismissed on sight — the FTUE's "flip it on whenever the app has earned it" made the app's job to notice. A5 is the daily digest for Active users, plus the parked tail (prepared plan tools, Q-agent-chat-openers). No new tables; every wave is a mode or key beside seams that already exist.
