**Pet species is a combobox: suggestions, any answer**: the species select made a guinea pig, ferret or axolotl an "Other". The box is now a text input with a `<datalist>` — the seven known kinds first, then `Pet::SPECIES_SUGGESTIONS` (guinea pig, hamster, parrot, gecko, goat…) — and it keeps whatever is typed. A typed "Cat"/"cats"/"CAT" is normalized to the `cat` slug the vaccine catalog, care kinds and toxics list read (matching the owner's words against our own labels, never guessing that an iguana is a reptile); anything else is stored squished and shown via `species_label`, and gets the generic wellness slate. `other` stays valid for existing rows; no migration. The new-pet tool's species input uses the same suggestions — `tool_runs/new` now renders any text input that carries `options` as a datalist combobox. The new form no longer defaults to Dog, so the suggestion list isn't filtered to one entry.
