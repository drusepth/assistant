**Quiz me on this: any note is study material (D-note-quiz)**: the Education hub's retrieval gate works, so it now points at the other place the user keeps things worth knowing. Every note page carries a **Quiz me on this** button: one click, no form — `Notes::QuizzesController` binds a `quiz_note` chat run to the note through `tool_runs.subject` the way a task's conversation is bound (D30), because the note *is* the input (D16). The tool is sectionless, its recap files where the note is filed, and with no model configured the button is simply absent rather than guessing questions. Notes shared with you can be quizzed — being quizzed on a study partner's note is the same act as reading it — while the run stays private to whoever took it, so the note page lists only your own past sessions. **The second flavor is the point of the branch.** A quiz files a recap note, so "quiz me on this" on *that* note would quiz its prose and ask "how did you do?" back at you. A recap is a report card, not material, so it points past itself: `Note#source_run` reads D19's paper trail backwards to the run that filed it, and the quiz runs on that run's topic, the review cards it minted from the misses, and — when the earlier quiz was itself on a note — the note the material actually lives in, walking back up a chain of recaps to a bounded depth and falling back to plain material if the walk finds nothing left. Finishing one that reaches the syllabus is evidence there like any other: forward-only mastery through `Topic#advance!` (D-mastery-evidence), the fresh misses into the FSRS queue, a `study_log` line — the same three writes `quiz_me` makes, via the same `EducationSupport` helpers, on the same Finish click (D20). Finishing one on an ordinary note just files a short recap. One assumption that was hiding in shared code came out on the way: the chat index and the run page both took "subject-bound" to mean "a task's", linking every such conversation to its item's page. That is true of a task, which hosts its chat as a panel, and false of a note, whose quiz is a session of its own — so it is a flag on the tool now (`hosted_on_subject`), the run page names whatever it's bound to instead of saying "task", and a subject-bound run offers its item rather than a "Run again" form it has no inputs for.
