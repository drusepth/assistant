**The instance can be handed back to the signup form (D-household-reset)**: `/admin` gained a "Reset this household" card — `Admin::HouseholdReset` destroys the household whole (every member account and everything they own, attachments purged inline rather than left to `purge_later` so the Storage panel is honest immediately, the members' error-log rows deleted first because `app_errors` keeps a foreign key to users without being cascaded from them), then clears the instance-wide leftovers — user-created lenses and the rest of the error log — only when the household that just went was the last one on the box. Confirmation is a typed `RESET`, not a dialog (a click-through is muscle memory by the third reset); the card names the counts about to go and points at Settings → Export first; the admin's own account goes too, so the redirect is `/setup` on a now-empty instance and sign-in otherwise. Testing the app no longer leaves permanent debris.
