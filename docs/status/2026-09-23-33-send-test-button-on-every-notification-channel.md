**Send-test button on every notification channel**: each channel listed under Settings → Notifications (webhook, email, browser push, SMS, Signal) now has a **Send test** button, so you can check a channel works before something real needs to reach you. `POST /notification_channels/:id/send_test` calls the new `Notifications::Deliver.test!(channel)`. It sends one fixed test message to that one channel straight away and raises on failure instead of only logging, so the page shows "Test sent" or "Test failed: <why>". A test on a metered channel counts toward its daily cap and is refused once the cap is used up. The action allows 5 tests a minute. Two fixes so failures show up at all: a webhook that answers non-2xx now raises a `DeliveryError` (before, a mistyped ntfy topic looked like a success), and an expired browser-push subscription raises after it disables itself. Covered by `test/controllers/notification_channel_tests_test.rb`.
