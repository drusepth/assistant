**Repeating tasks (routines) and an Add a task button on the pet page**: the pet page header has "Add a task" next to "Add an appointment", opening the task form tagged with the pet's lens. The task form has a Repeat picker (every day / weekday / week on chosen days / 2 weeks / month / year, a start day, a time, an optional last day), which makes the task a routine (D-task-routines, resolving Q-routines). Each time it comes round, the same task reopens, moves into Today and pings. It works for litter changes, food runs and trash night. The cadence rides a standing reminder attached to the task, so there is no second recurrence engine. Picking "Doesn't repeat" stops the routine and leaves the task's other reminders alone.
