**Pet details card: its own Edit and a list of what's blank**: the Details card on a pet's page hides every blank row, so a newly added pet showed one line ("No vet on file") and looked read-only. The only way into the form was the Edit button up in the page header. The card now carries its own Edit in its top-right (owner only, through the `Ui::CardComponent` actions slot), and when sex, markings, date of birth, weight or microchip number is blank it ends with a link naming them ("Add sex, markings, and weight"). Editing still happens in the one form: no in-place fields that would need to repeat the sex → pronoun and estimated-birthday logic.
