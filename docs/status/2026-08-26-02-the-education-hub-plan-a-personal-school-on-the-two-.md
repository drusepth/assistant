**The Education hub plan: a personal school on the two-sigma play (`docs/EDUCATION_PLAN.md`)**: the placeholder hub (two tool cards and an empty state) now has a full build plan for what it becomes — the section that lets every household member learn anything at their own pace, taught through their own interests, with progression measured the way the learning science says to. The frame is Bloom's two-sigma problem run in reverse: school holds time fixed and lets mastery vary (grades); this hub holds mastery fixed and lets time vary, which is only possible 1:1 — exactly what a self-hosted tutor makes free. Five decisions: **D-education-spine** (Subject + Topic join the primitives as a per-learner curriculum tree — `Visible`, `Sectionable`, multi-tagging like everything else, with the doing layer staying on Goals/Tasks/Notes), **D-curriculum-commons** (core subjects as open, editable YAML outlines in the repo, informed by public standards; enrolling instantiates a personal tree, "learn anything" generates the same shape through a second door, and everything works dry with no model configured), **D-mastery-evidence** (`unseen → learning → practicing → mastered` + the honest `rusty` demotion; advancement on retrieval evidence only, no letter grades, no seat time, pace only against the learner's own target), **D-review-scheduler** (first-class review items on FSRS — deterministic arithmetic schedules, the model only writes and grades cards; the daily queue interleaves across subjects), and **D-learning-record** (portfolio/transcript/hours-log generators over the spine plus a durable `study_logs` table, since ToolRuns prune at 90 days — evidence, never accreditation). The plan also specs the redesigned hub (do → continue → begin → oversee → prove, phone-first, per D37), the tool slate (learn_something and tutor upgraded to be curriculum-aware; placement, quiz_me, explain_this, progress_report new), the two personalization mechanisms kept named apart (suggested subjects from the other lenses via a deterministic affinity map + model extension; interest framing threaded through every teaching prompt — and framing can never fake mastery, because advancement gates on retrieval), five D20-deterministic watchers, and the household story (learners are real household Users; parent oversight exists only where an explicit grant made it exist). Six build waves, W1–W3 being the two-sigma core; four open questions (jurisdiction datasets, external assessment anchors, open-materials reading lists, FSRS tuning). Design only this branch — nothing is built yet.
