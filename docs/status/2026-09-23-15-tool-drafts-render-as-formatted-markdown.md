**Tool drafts render as formatted Markdown**: every draft tool's body came back as Markdown — nothing asked for it, but the prompts are written in it (`**The first hour**`, numbered sections) and the model mirrors them — and the run page, the prepared-draft card and the note page all printed it as `whitespace-pre-wrap` text, so a lost-pet sheet was a wall of `##`, `**` and broken pipe tables. The diary's safe renderer moved up to a shared `Markdown` (escape first, then only tags it writes) and grew what drafts use: tables — including the row a model breaks across lines to fit a bulleted list in a cell, and literal `<br>`s in cells — nested and wrapped list items, numbered lists that keep counting across blank lines, `•` bullets, deeper headings and rules. `.diary-prose` became `.prose-body`: `##` sections get the accent colour and a hairline, and `.prose-table` folds each row into a labelled card below `sm`. `DRAFT_FORMAT` now says the body is Markdown and asks for one-line table rows; letters keep their own plain-prose contract. Note cards preview through `Markdown.plain`.
