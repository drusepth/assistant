**The Career section is built out (D-career-signal, `docs/CAREER.md`)**: career signal climbs a ladder — granted data first (pay-stub-aware `Documents::Analyze` extraction into `documents.extracted_facts`, whitelisted by code; rate changes vs the previous same-employer stub auto-land as Career-tagged "Comp change:" Events with provenance via `Career::RecordCompChange`; LinkedIn's official Connections.csv joins the People importers, preamble handled), manual always (Career-page capture card: one-tap win log with "Win:" Notes + comp-change logging, `Career::WinLog`/`CompChange`, manual beats parser), inference never (every nudge cites its source). Eight tools on existing seams (a `:textarea` input kind is the only DSL growth): **interview_prep** (wins mapped to the listing's asks, company facts as a research checklist, routes to **mock_interview** — chat that coaches each answer from the tracked record), **tailor_application** (never-fabricate footer appended by code to bullets + cover letter), **check_pay_stub** (model explains the lines, `Career::PayStubAudit` does the arithmetic — hours × rate vs gross, missing OT, rate drops, new deductions — and short pay routes to **wage_claim**, whose state-agency/retaliation footer is code), **raise_case** (code-computed tenure math + wins grouped by business impact + BLS/state fetch-list, routes to negotiation_prep), **decode_offer** (total comp as written, benefits translated, neutral red-flag scan, expiry on the calendar), **lost_my_job** (the second Situation: unemployment-this-week, the COBRA/marketplace fork, bill triage, the story, then the search) and **plan_job_search** (record first, tracked per-employer cadence), **find_my_next_move** (chat; context spans Career + Hobbies + Education, non-degree paths always included, cheap tests before tuition), **accommodation_request** (share-only-what's-needed + EEOC footer by code); decode_letter routes employer mail to decode_offer/wage_claim. Four watchers: **raise_cadence** (year-quiet timeline → raise-case nudge, yearly buckets; no timeline → one lifetime invitation), **stub_anomaly** (newest failing stub → one heads-up per stub), **interview_ahead** (upcoming interview event with no prep run → prefilled prep offer), **application_follow_up** (10-day-quiet application tasks, capped at three, monthly buckets).
