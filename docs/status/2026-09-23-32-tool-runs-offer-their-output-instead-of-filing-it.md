**Tool runs offer their output instead of filing it**: a draft tool run (gift ideas, dispute letter, …) no longer drops its note and follow-ups into Notes and Tasks automatically (D-tool-run-offers). `ToolRunJob` runs draft tools in the existing `preparing` mode and stores the staged intents on the run; the run page (`tool_runs/_offers`) shows the note with **Save to notes** and each task/date with **+ Add**, plus **Add everything**. New `ToolRun#offers`, `#add_offer!(index)`, `#direct_items`, and a `POST /tool_runs/:id/add` route; `land` now also serves as "Add everything" on a done run. The tailor-application email panel prefills from the cover-letter offer when it hasn't been saved. Tool content tests use a new `run_and_add_all` helper; `tool_run_job_test` and the controller test cover staging, single add, idempotence and Add everything.
