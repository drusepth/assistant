**Person picker on tool forms and the pet vet field** (D-person-picker): the last places that listed the whole address book — every tool's "Who's it for?" person input (Reconnect, Gift ideas, What do I say) and the pet form's Vet `<datalist>` — are now the type-to-find picker in a form-field mode where a pick fills the field instead of submitting. A typed name in a tool form is resolved on submit (existing contact by exact name, else a new contact), so a tool can be run for someone not yet in the Address Book. New `for=any` scope on `/people/matches`.
