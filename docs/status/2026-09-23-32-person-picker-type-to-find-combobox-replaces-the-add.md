**Person picker: type-to-find combobox replaces the address-book dropdowns**: every "put a person here" control — the People page's circle capture, each group card, a group's page, and a photo's tags — is now one combobox (`Ui::PersonPickerComponent` + `person_picker` Stimulus controller) instead of a `<select>` over the whole address book plus a separate "…or someone new" field (D-person-picker). Typing fetches up to eight matches from `GET /people/matches` (option rows with avatars, prefix matches first, people already there left out) and offers "Add “X” — new contact" when the name is nobody's; picking submits, arrow keys and Escape work, and the listbox carries the ARIA combobox roles. `People::Picker` holds the pools and `resolve`, which reuses an exact case-insensitive name before creating — so Enter-without-picking and the no-JS path can't duplicate a contact. The People page's lead capture now shows only while the circle is empty (the circle card's "Add someone" takes over after, focusing the field when opened), and the page no longer renders the roster into its HTML. Photo tagging can create a new contact by name.
