**The assistant can text you now**: D22 shipped the three notification channels that assume nothing — a pasted webhook URL, Web Push, email if the instance has SMTP — and left "text me" to a bridge the user was expected to wire up themselves, which is exactly the wrong thing to ask of the person least able to run infrastructure. SMS is now a channel kind of its own (D-sms-channels), built the way the model layer treats model providers: a registry of providers, one transport class each, and which one a household uses is a Settings choice rather than an integration. Three ship. **gammu-smsd** is the one the mission actually wants — a GSM modem and your own SIM, no account, no per-message fee, nobody in the path, and the only channel that still works when the box has no outbound internet; delivery is a file drop into the daemon's FILES-backend outbox, staged under a name the scanner ignores and then renamed, because an atomic rename is what stops gammu picking up a half-written message. **Twilio** and **Amazon SNS** cover the commodity half — both a plain form POST, with SNS's Signature V4 written out as thirty lines of HMAC rather than pulling the AWS SDK onto a self-hosted install for one request (the chain is checked against AWS's own `get-vanilla` test vector, since a signature that is merely shaped right is a 403 you debug at 2am). **signal-cli-rest-api** lands as a fourth kind and is quietly the best of them wherever the recipient has Signal: free, end-to-end encrypted, and no carrier keeps a copy. Two things exist only because a phone is involved. Provider credentials go in a new `secrets` column encrypted at rest, the `linked_accounts.credentials` shape, with the registry marking which fields are secret so an auth token can never land in the plain `config` that Settings renders back. And every text is metered — SMS is the first channel that costs money per message, so a per-channel daily cap (default 10) is checked before sending and counted only after a send succeeds, because "Active sections only" bounds which watchers may speak, not what a chatty week costs. The D22 payload rule is unchanged and now has a length bound on top: counts and titles, never bodies, truncated to two GSM segments — a lock screen is not private, and a carrier keeps a copy of everything besides. Still one-way; the reply path that would let it ask a question and hear back is written up as Q-sms-replies, and the timed-reminder half it would need as Q-scheduled-reminders.
