**Section picker stops offering other members' private pets**: a pet's lens is a household-wide section, but the pet behind it is private (D9). Every form's section picker offered each enabled section's children, so another member's private cat showed up as a tag you could file under. The picker now leaves out the lenses of pets the viewer can't see. This branch also adds regression tests for the bug that started it: a vet contact made from the pet form was offered "Add to group → Dimitri". That bug was fixed at the root when D-pets-section moved pet lenses from People to Pets; this branch's own column-based fix (owner_type on sections) was dropped in the merge as redundant.
