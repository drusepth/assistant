**The /about screenshots: a capture pipeline, and photos for the map**: `bin/rails screenshots:capture` seeds the demo household, drives a real browser over it and writes 18 WEBP images into `app/assets/images/about/` — 712KB for the lot — which now appear on the index, all ten hubs and fourteen feature pages. This finishes ABOUT_PLAN wave 5. It is written as a system test under `test/system/`, which `bin/rails test` skips, so it gets a browser and a server for free and can never fire during an ordinary run. Three parts with deliberate seams: `About::Shot` is one registry read by both the capture and the views so they cannot disagree; `about_screenshot` renders a shot *or nothing at all*, because a checkout can legitimately be missing an image and the failure has to be an absent figure rather than a broken image on a public page; and `about_shots_test.rb` pins all three directions — no view asks for an unregistered shot, no registered shot is uncaptured, no captured file goes unrendered, nothing exceeds 250KB. The demo gained 30 generated photographs with real coordinates first, because the world-map page is the one where the screenshot *is* the feature and an empty map sells nothing; they are abstract colour bands rather than pictures, which is all a thumbnail grid and a map of pins need, and the resulting map draws Ohio, Florida, Toronto and Galway without fetching a single tile. Two environment lessons worth keeping. `ApplicationSystemTestCase` now takes `CHROME_BINARY` and `CHROMEDRIVER` and otherwise searches PATH, because Selenium's default is to find Chrome or download one and a container has neither — and the two **must match on major version**, which surfaces as a session error that does not say so. And `webmock/minitest` blocks every outbound connection including the runner's own localhost talk to chromedriver, so system tests re-allow localhost and nothing else. The layout's footer now states that every screenshot is of a household we invented; a site arguing this hard about privacy should say where its pictures came from.
