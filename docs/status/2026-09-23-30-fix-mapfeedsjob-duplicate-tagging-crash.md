**Fix MapFeedsJob duplicate-tagging crash**: `MapFeedsJob` raised `RecordInvalid: Section has already been taken`. `Hobbies::OtherInterests.claim!` computed the lenses a feed gains against its *preloaded* `sections`, so a feed another mapping job filed in the meantime (an OPML import enqueues overlapping jobs) got the same tagging inserted twice — as did a model reply naming one slug twice for a feed. `claim!` now de-duplicates the lenses, re-reads the feed's taggings before diffing, and treats losing a genuine race on the unique index as "nothing to add". Two regression tests in `map_feeds_test.rb`.
