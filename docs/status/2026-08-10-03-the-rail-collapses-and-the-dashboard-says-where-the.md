**The rail collapses and the dashboard says where the model runs (`Assistant Dashboard.dc.html` 2a, the layout half)**: the design's remaining un-built pieces were all in the sidebar. The rail now **collapses to a 68px icon strip** behind the chevron — labels ride a single `nav-label` class so a new nav row only has to mark its text, section dots sit in a fixed-width slot so the collapsed column stays flush, every row keeps a `title` because collapsed the icon is the only affordance, and the choice persists in `localStorage` (restored on `connect()`, so a Turbo morph doesn't expand it). Collapsing is deliberately **desktop-only**: the same `<aside>` is the off-canvas drawer below `lg`, and a drawer you opened on purpose should never be a strip of unlabelled icons — so all three collapse rules and the toggle button are `lg`-gated, and a stored preference cannot reach the phone. The rail's *width* is the one property that stays a utility (`lg:data-[nav-collapsed=true]:w-[68px]`) rather than moving into the components layer with the rest: `@layer components` cascades **before** Tailwind's utilities, so anything there colliding with `w-64` on the same element loses on layer order no matter how specific the selector is — specificity tricks (`.nav-rail.nav-rail`) don't help across layers. The three settings destinations fold into a **popover** above the user button (new generic `popover` controller), taking the rail's foot from four rows to one and moving Sign out — the only thing there you could hit by accident — behind a click. And the dashboard gains the design's **"Running on your machine"** card, which is the one place the app makes a claim about *itself*: the mock's "Local model · last scan 12 minutes ago" is only printed when it's true, so a custom endpoint on this box reads "Local model — …", anything else reads "Remote model — …", an unconfigured household says so, and the scan half reports `digest_generated_at` or admits the first scan hasn't run — a card implying local processing while an API key ships text to a vendor would be the most dishonest pixel in the product. Writing its test surfaced a real pre-existing bug: `ModelProfile#display_name` called `URI()` unguarded on the free-text `base_url`, so a malformed custom endpoint would have taken the whole dashboard down over a cosmetic label — now `endpoint_host` rescues and falls back to the raw value.
